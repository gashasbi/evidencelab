# External references

This page lists primary project and standards references relevant to EvidenceLab's architecture. External resources evolve independently; record access dates and exact versions in a study rather than treating a web page as a pinned artifact.

- Joern documentation: https://docs.joern.io/

- Joern Code Property Graph overview: https://docs.joern.io/code-property-graph/
- Joern export: https://docs.joern.io/export/
- Joern data-flow steps: https://docs.joern.io/cpgql/data-flow-steps/
- Joern slicing: https://docs.joern.io/cpg-slicing/

## How to use these references

The references describe upstream tools, source data, taxonomies, or standards. They do not imply that EvidenceLab implements every capability of those ecosystems or fully ingests every source version. When a study uses an external tool or corpus, record the exact release, acquisition path, license, relevant configuration, and checksums.
